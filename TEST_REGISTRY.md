## PURPOSE

Single source of truth for all test cases across the project. No test is run unless it is registered here. No implementation is considered complete unless its required test cases are registered in this file and PASSING.

**Implementing agent rule:** Read this file in Phase 1 (ANCHOR). Register new tests in Phase 2 (TEST-FIRST) before writing any implementation. Update status column after each test run.

---

## TEST ID FORMAT

```
Format: T-[MODULE]-[TYPE]-[SEQ]

MODULE codes (3 letters):
  ENV  — Environment setup / check_env.py
  GAT  — Gateway (LiteLLM / gateway.py)
  DEL  — Delivery (email / delivery.py)
  ORC  — Orchestration (ReACT agent / orchestration.py)
  TOOL — SDK-direct tool loop (core/tool_agent.py)
  SCH  — Scheduler (launchd)
  DB   — Database (SQLite / schema.sql)
  MEM  — Memory / cooldown tools (tools/memory.py)
  SRC  — Search tools (tools/search.py)
  TOP  — Topic manager (tools/topic_manager.py)
  SYN  — Synthesis / HTML rendering (synthesis.py)
  SEC  — Security (pre-commit scans, ZT rules)
  INT  — Integration (cross-module / end-to-end)
  NORM — Output normalization (core/output_normalize.py)

TYPE codes (1 letter):
  C  — Core (happy path)
  E  — Edge case
  N  — Negative scenario
  I  — Integration
  S  — Security

SEQ: 3-digit sequence within module+type, e.g. 001, 002
```
